# 第三方订阅渠道

在 **设置 → 模型** 页面，现有「第三方模型提供商」和「自定义模型 API」之后新增一个入口 **第三方订阅渠道**：登录你已有的订阅账号，然后直接使用账号里自带的模型，不需要另买 API Key。

## 支持的渠道

| 渠道 | 登录方式 | 使用的能力 |
| --- | --- | --- |
| ChatGPT 订阅（Codex） | 浏览器 OAuth（PKCE，回环回调） | 账号内的 Codex / GPT 系列模型 |
| Google Antigravity | 浏览器 OAuth（PKCE，回环回调或粘贴授权码） | Antigravity 账号内的模型 |
| Claude 订阅（Pro / Max） | 浏览器 OAuth（PKCE）或粘贴授权码 | 账号内的 Claude 系列模型 |

## 使用步骤

1. 打开 **设置 → 模型**，在「添加模型提供商」下方点击 **第三方订阅渠道**。
2. 在要使用的渠道上点击 **登录**；插件会打开浏览器登录页（或给出一段可粘贴的授权码输入框）。
3. 授权完成后该渠道显示为「已登录」，账号内的模型随即出现在输入框的模型选择器里。
4. 不再使用时点 **退出登录**，本地保存的令牌会被删除，对应模型从选择器里消失。

## 模型目录与检测

登录后点渠道卡片上的 **编辑** 打开 **模型目录**（与 DSH 自带「自定义模型 API」面板同构）：

- 每行：拖动排序、模型 ID、显示名称、展开、删除；删除立即从编辑器移除。**获取可用模型** 弹窗列出可用模型（默认勾选被移除项），确认后加回；**恢复默认模型** 清掉全部改动。
- 展开 **模型选项**：上下文窗口、最大输出 token 数（`131072` / `256K` / `1M`）、输入类型（文本 / 图片）、推理等级（开关 + 档位/API 参数值，可增删档位）；`+ 添加模型` 可加入账号目录外的模型 ID。
- 行内 `检测` 或头部 `检测全部` 发起一次最小真实请求，给出可用与延迟，或失败原因（授权失效、额度用尽、限流、模型不存在、上游异常、超时、网络错误）。
- 目录与改动保存在 `<DSH_HOME>/subscription-channels/catalog.json`；删除只影响选择器，已有会话仍可继续。

## 说明与限制

- 令牌保存在 DSH 的凭据库中（记录键为 `dsh-subscription-channels/<渠道>`），不会写入配置文件或日志；刷新令牌会在过期前自动换取新的访问令牌。
- 三个渠道使用的都是各订阅产品自身客户端所用的 OAuth 客户端参数与接口，属于非官方公开接口，上游随时可能调整；参数可在插件配置里覆盖。
- Google Antigravity 的 OAuth client secret 不在本插件里分发，需通过 googleClientSecret 配置或 DSH_ANTIGRAVITY_CLIENT_SECRET 环境变量提供，详见仓库 README。
- 图片输入只在把模型输入类型勾选「图片」后转发；文件附件仍不转发。
- 登录需要本机浏览器；如果在无图形界面的环境里使用，请选择「粘贴授权码」方式。
